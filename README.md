# 오늘의 운세 🔮

버튼을 누르면 카드가 3D로 뒤집히며 랜덤 운세와 행운의 아이템이 나타나는 Next.js 사이트입니다.

## 기능

- 별이 반짝이는 밤하늘 배경 위 수정구(🔮) 운세 카드
- `운세 뽑기` 버튼 클릭 시 카드가 Y축으로 회전하며 뒷면으로 뒤집힘
- 10가지 운세(대길·행운·재물운·인연·건강 등) 중 랜덤 등장
- 각 운세마다 **행운의 아이템 / 색 / 숫자** 표시
- `다시 뽑기`로 새 운세 확인

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 기술 스택

- Next.js 14 (App Router)
- React 18
- CSS Modules (3D transform 애니메이션)
